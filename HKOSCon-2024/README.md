This folder contains items I shared in [HKOSCon 2024](https://hkoscon.org/2024/topic/building-your-own-jarvis-exploring-llm-integration-options-home-assistant/), including:

- [Presentation_Deck.pdf](Presentation_Deck.pdf): 

	The slides I presented at the conference.
	
- [Gemini1.5Pro-VideoDoorBell-Demo.mp4](Gemini1.5Pro-VideoDoorBell-Demo.mp4):

	A demo video showing how Home Assistant can send a video push notification whenever a movement event is triggered through the community-maintained Arlo video integration, with vidceo analysis performed by Gemini 1.5 Pro model via Home Assistant's Gemini integration.
	
- [Gemma2-LensesBox-Cantonese-Demo.mp3](Gemma2-LensesBox-Cantonese-Demo.mp3):

	A Cantonese TTS demo showing how Home Assistant can broadcast a warning message whenever the humidity inside the camera lenses box is detected by the Xiaomi Temperature and Humidity sensor to be over the threshold value. The message was processed by the Gemma 2 model via Home Assistant's Local LLM integration.
	
- [OpenAI_GPT4o-PersonalAdvice-Cantonese-Demo.mp3](OpenAI_GPT4o-PersonalAdvice-Cantonese-Demo.mp3):	

	A Cantonese TTS demo showing how Home Assistant can broadcast a personalized daily summary message at a specific time every morning. The message was processed by the OpenAI GPT-4o model via Home Assistant's OpenAI Integration.
