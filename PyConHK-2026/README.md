This folder contains items I shared in [PyCon Hong Kong 2026](https://pretalx.com/pyconhk2026/talk/97YVA8/), including:

- [Presentation_Deck.pdf](Presentation_Deck.pdf): 

	The slides I presented at the conference.

- [AI-rendered video demonstrated in the talk](https://drive.google.com/file/d/1RxacOXsEAAhUMTV4ttNMAYMw2sLC57Yj/view?usp=drive_link): 

	Original AI-rendered video, framing common problems of scattered smart home apps and ecosystems, cloud performance overheads, cloud privacy concerns, and service sustainability, into a one-minute short story. Spoken language in Cantonese. Generated locally using MiniMax H3 model in ComfyUI; upscaled to 4K using Topaz Video AI 5.5.1, using the Theia model.

	The same video is also available in [YouTube](https://www.youtube.com/watch?v=7FOzO0RKLHM), with English closed captions.
	
- [AI-Video/Video_ComfyUI.json](AI-Video/Video_ComfyUI.json):

	Source ComfyUI file of the AI-rendered video, containing scene prompts, model settings and scene configurations.
	
- [AI-Video/Scene-FFLF-Pics](AI-Video/Scene-FF-LF-Pics/):

	This sub-folder contains images generated with ChatGPT Images 2.6 for First Frame and Last Frame scene generation.
